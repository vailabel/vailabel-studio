# Sample data credits

Every file in this folder is real data under an open license, bundled so that
**Projects → Samples** can create a ready-to-label project for each template
offline. Files were resized, trimmed or re-encoded for size; nothing else was
changed. Text excerpts used inline by the seeder
(`src/features/projects/model/seed/sample-texts.ts`) are credited at the end.
